## Loops
```python
names = []
for name in names:
    if 'h' in name.lower():
        # break terminates the loop
        # continue skips over the iteration and goes to the next
        # pass does nothing
        break

for i in range(0, 10):
    print(i)

while 1:
    print("True")
```

 `break`: "Exit the loop"
 `continue`: "Go directly to the next iteration of this loop"
